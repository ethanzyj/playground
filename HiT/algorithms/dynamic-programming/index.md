# Dynamic Programming

Source: https://www.hiredintech.com/algorithms/dynamic-programming/

Dynamic programming is a very widely used technique. It is likely that you would get a problem requiring DP at interviews. It is useful knowledge for many software engineers.

## About dynamic programming

DP is a method that allows you to solve a problem by breaking it down into smaller sub-problems. You identify a way to combine answers for smaller versions to compute the answer for a bigger version. Start with trivial base cases and subsequently compute bigger and bigger versions.

The technique of storing answers for smaller versions and reusing them is called "memoization".

# 动态规划

来源：https://www.hiredintech.com/algorithms/dynamic-programming/

动态规划是一种非常广泛使用的技术。你很可能在面试中遇到需要动态规划的问题。这对许多软件工程师来说都是有用的知识。

## 关于动态规划

动态规划是一种通过将问题分解为更小的子问题来解决问题的方法。你需要找到一种方式，将较小版本的答案组合起来计算较大版本的答案。从简单的基础情况开始，逐步计算越来越大的版本。

存储较小版本的答案并重复使用的技术称为"记忆化"。
