# Popular Sorting Algorithms

Source: [https://www.hiredintech.com/algorithms/sorting/popular-sorting-algorithms/](https://www.hiredintech.com/algorithms/sorting/popular-sorting-algorithms/)

Simplest: selection sort and bubble sort. Both O(N^2).

More efficient: quick sort, merge sort, heap sort.

Key differences:
- Selection sort: always O(N^2) regardless of input
- Bubble sort: O(N) for already sorted input, O(N^2) worst case
- Quick sort: O(N^2) worst case depending on implementation
- Heap sort and merge sort: always O(N*logN) regardless of input

These differences between seemingly similar algorithms matter. Interviewers may test your knowledge here.

# 常见排序算法

来源：[https://www.hiredintech.com/algorithms/sorting/popular-sorting-algorithms/](https://www.hiredintech.com/algorithms/sorting/popular-sorting-algorithms/)

最简单的：选择排序和冒泡排序。都是 O(N^2)。

更高效的：快速排序、归并排序、堆排序。

关键区别：
- 选择排序：无论输入如何始终 O(N^2)
- 冒泡排序：已排序输入为 O(N)，最坏情况 O(N^2)
- 快速排序：根据实现，最坏情况可能 O(N^2)
- 堆排序和归并排序：无论输入如何始终 O(N*logN)

这些看似相似的算法之间的差异很重要。面试官可能会测试你这方面的知识。
