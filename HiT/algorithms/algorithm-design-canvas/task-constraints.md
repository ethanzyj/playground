# Task Constraints

Source: https://www.hiredintech.com/algorithms/algorithm-design-canvas/task-constraints/

You never want to solve a problem that's ill-defined. That's why the very first thing you should turn your head to when it comes to algorithm design problems is the problem's constraints.

## The importance of constraints

Developing an algorithm that sorts 50 numbers is going to be fundamentally different from developing an algorithm that sorts 5 billion strings, each one 1 million characters long. So if someone told you "design an algorithm that sorts an array", you'd better not start coding a solution right away. Among other things, you need to understand things like what's in the array, and how large the array can get.

You're probably aware that interview problems have a bunch of constraints, which tell you how efficient your solution should be. What is less obvious is that interviewers don't always give you all the information needed. They expect you to be asking clarifying questions. Don't be alarmed if not everything is clear in a problem statement, this is your chance to make it so.

## How do you figure out the right questions?

The Algorithm Design Canvas helps you collect the needed information at an interview. It has a section where you need to fill in all the important constraints in a problem. If you use it while practicing you will get into the habit of making sure you know everything that you need to design an efficient solution.

Filling in the Constraints box is nothing more than asking the interviewer the right questions. Every problem's different, but to get you started we've compiled a pretty extensive list of common things you should keep an eye on - the Common Constraints Handout.

# 任务约束

来源：https://www.hiredintech.com/algorithms/algorithm-design-canvas/task-constraints/

你永远不想解决一个定义不清的问题。这就是为什么面对算法设计问题时，你首先应该关注的是问题的约束条件。

## 约束的重要性

开发一个排序 50 个数字的算法与开发一个排序 50 亿个字符串（每个 100 万字符长）的算法有着根本区别。所以如果有人告诉你"设计一个排序数组的算法"，你最好不要立刻开始编码。在其他事情之外，你需要了解数组里有什么以及数组可以有多大。

你可能知道面试问题有一系列约束条件，这些约束告诉你解决方案应该有多高效。不太明显的是，面试官并不总是给你所有需要的信息。他们期望你提出澄清性问题。如果问题描述中不是所有内容都清楚，不要慌张——这是你让它变清楚的机会。

## 如何找出正确的问题？

算法设计画布帮助你在面试中收集所需信息。它有一个部分需要你填写问题中所有重要的约束。如果你在练习时使用它，你就会养成确保了解设计高效解决方案所需一切信息的习惯。

填写约束框无非是向面试官提出正确的问题。每个问题都不同，但为了帮助你入门，我们编制了一个相当全面的常见注意事项列表——常见约束手册。
