# How to Practice?

Source: https://www.hiredintech.com/algorithms/algorithm-design-canvas/how-to-practice/

At this point, you've mastered the theoretical underpinnings of the Algorithm Design Canvas. The next fundamental question is how to most efficiently apply it in practice.

## Practice with HiredInTech

In the next sections you will find suggested practice tasks ordered by topic with learning materials for each topic.

## Use online judges

Online judges such as LeetCode are an indispensable tool. There's nothing like practicing getting a problem 100% correct. Other sites: Codechef, Codeforces.

## Always follow the Canvas

Many people feel tempted to skip certain areas during practice. This is not a good idea. The Canvas is designed to build up all aspects of your interviewing chops.

## Forget about your IDE

Writing code in your IDE is fundamentally different from coding outside of it. Write your code in the Canvas "Code" section or in the online judge's editor.

## Read through your code

Don't immediately try to run code. Spend time reviewing it. Be 100% confident it will compile AND run correctly before hitting "Run Tests". This practice of carefully inspecting your code is priceless at interviews.

## Summary

- Sign up for an automated online judge like LeetCode.
- Always follow the Canvas, even on simpler problems.
- Don't use your IDE so that you can train your interview coding skills.
- Read and review your code before compiling and running.

# 如何练习？

来源：https://www.hiredintech.com/algorithms/algorithm-design-canvas/how-to-practice/

到目前为止，你已经掌握了算法设计画布的理论基础。接下来的根本问题是如何最有效地将其应用于实践。

## 使用 HiredInTech 练习

在接下来的章节中，你将找到按主题排列的推荐练习任务和每个主题的学习材料。

## 使用在线判题系统

LeetCode 等在线判题系统是不可或缺的工具。没有什么比练习完全正确地解决问题更好了。其他网站：Codechef、Codeforces。

## 始终遵循画布

很多人在练习时想跳过画布的某些区域。这不是一个好主意。画布旨在全面培养你的面试能力。

## 忘掉你的 IDE

在 IDE 中写代码与在外面写代码有根本不同。在画布的"代码"区域或在线判题系统的编辑器中编写代码。

## 通读你的代码

不要立刻尝试运行代码。花时间审查它。在点击"运行测试"之前，确保你 100% 相信代码可以编译并正确运行。这种仔细检查代码的习惯在面试中非常宝贵。

## 总结

- 注册一个自动在线判题系统，如 LeetCode。
- 即使是简单问题也始终遵循画布。
- 不要使用 IDE，以便训练你的面试编码技能。
- 在编译和运行之前阅读和审查你的代码。
