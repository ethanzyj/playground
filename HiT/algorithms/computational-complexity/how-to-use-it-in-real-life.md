# How to Use It in Real Life?

Source: [https://www.hiredintech.com/algorithms/computational-complexity/how-to-use-it-in-real-life/](https://www.hiredintech.com/algorithms/computational-complexity/how-to-use-it-in-real-life/)

The best way to get proficient is to practice. Take different algorithmic problems and their solutions and try to evaluate the time and memory complexity.

## Evaluating if a solution is fast enough

If the time complexity is O(N^2) and N can be as big as 10,000, is that good? It depends on:
1. The time constraints you are under
2. The machine(s) where the solution will run

With time you will build better intuition about how quick a solution will really be.

## Comparing solutions

Knowing time or memory complexity of different solutions to the same problem gives you the ability to compare them and decide which is better, or what trade-offs are required.

## Memory considerations

With C it's easier to know exactly how much memory is used. With higher-level languages (C++ STL, Ruby, Java, Python), you may need to experiment. But knowing the memory complexity gives a good expectation.

# 如何在实际中使用？

来源：[https://www.hiredintech.com/algorithms/computational-complexity/how-to-use-it-in-real-life/](https://www.hiredintech.com/algorithms/computational-complexity/how-to-use-it-in-real-life/)

变得熟练的最好方法是练习。选择不同的算法问题及其解法，尝试评估时间和内存复杂度。

## 评估解决方案是否足够快

如果时间复杂度是 O(N^2) 且 N 可以大到 10,000，这够好吗？取决于：
1. 你的时间约束
2. 解决方案运行的机器

随着时间推移，你会建立更好的直觉来判断给定复杂度和输入规模下解决方案的实际速度。

## 比较解决方案

了解同一问题不同解决方案的时间或内存复杂度，使你能够比较它们并决定哪个更好，或者需要什么权衡。

## 内存考量

使用 C 语言更容易精确知道使用了多少内存。使用更高级别的语言（C++ STL、Ruby、Java、Python），可能需要实验。但了解内存复杂度能给出一个很好的预期。
