# At the Technical Interviews

Source: https://www.hiredintech.com/algorithms/computational-complexity/at-the-technical-interviews/

Computing and discussing the complexity of a solution will come up very often at tech interviews. You should be able to identify the time and memory complexity fairly fast - almost instantly. No complicated math is expected. Most likely standard complexities.

Training is the best way to become smooth. As you solve problems using the Algorithm Design Canvas, always fill in the complexity box.

> Practice shows that usually time complexity is somewhat more discussed. However, there is often a tradeoff between time and memory. A solution can be tweaked to use more memory and become faster, and vice versa. In such cases, ask the interviewer which resource is more valuable.

## Summary

- Why time and memory complexity are so important at coding interviews.
- Given an algorithm, how to figure out its complexity.
- Given an algorithm's complexity, build intuition about whether it's "sufficient": fast enough and reasonable memory given the constraints.

# 在技术面试中

来源：https://www.hiredintech.com/algorithms/computational-complexity/at-the-technical-interviews/

计算和讨论解决方案的复杂度在技术面试中会经常出现。你应该能够相当快地——几乎是即时地——识别时间和内存复杂度。不需要复杂的数学，大多数情况下都是标准复杂度。

训练是变得流畅的最好方法。当你使用算法设计画布解决问题时，始终填写复杂度框。

> 实践表明，时间复杂度通常被讨论得更多。然而，时间和内存之间经常存在权衡。解决方案可以调整为使用更多内存来变得更快，反之亦然。在这种情况下，问面试官哪种资源更宝贵。

## 总结

- 为什么时间和内存复杂度在编程面试中如此重要。
- 给定一个算法，如何计算其复杂度。
- 给定算法的复杂度，建立直觉判断它是否"足够"：在给定约束下是否足够快、内存使用是否合理。
