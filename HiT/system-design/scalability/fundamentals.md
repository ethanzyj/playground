# Fundamentals

Source: https://www.hiredintech.com/system-design/scalability/fundamentals/

Now that you've designed a solid abstract architecture, the next step is to take it to scale. If you've never built a large-scale system, this task may seem a little daunting.


## Where do you start?

There is a common set of scalability principles that you need to know. Knowing what they are, understanding how they are used, and being able to discuss their pros and cons is what scalability at interviews is all about.

How do you build up that intuition?

The first thing we'd recommend you to do is watch the Harvard scalability lecture by professor David Malan. It teaches a huge part of the intuition you will need to have when it comes to scalability. After watching it, you should have a good fundamental understanding of the following concepts:

- Vertical scaling
- Horizontal scaling
- Caching
- Load balancing
- Database replication
- Database partitioning

Next, we recommend reading a great 4-post "Scalability for Dummies" tutorial. It reiterates on some of the topics mentioned above, but also introduces several important new concepts:

- Using NoSQL instead of scaling a relational database
- Being asynchronous

You would also know how to deal with the two major bottlenecks: handling a lot of users, and handling a lot of data.

Finally, you may want to read a tutorial on Database sharding. It's a very common and powerful way of database scaling.

# 基础知识

来源：https://www.hiredintech.com/system-design/scalability/fundamentals/

现在你已经设计了一个可靠的抽象架构，下一步是让它具备扩展能力。如果你从未构建过大规模系统，这项任务可能看起来有点令人生畏。


## 从哪里开始？

有一组通用的可扩展性原则是你需要了解的。了解它们是什么、理解它们如何使用、并能够讨论它们的优缺点——这就是面试中可扩展性的全部内容。

如何建立这种直觉？

我们建议你做的第一件事是观看哈佛大学David Malan教授的可扩展性讲座。它教授了你在可扩展性方面需要具备的大部分直觉。观看之后，你应该对以下概念有良好的基础理解：

- 垂直扩展
- 水平扩展
- 缓存
- 负载均衡
- 数据库复制
- 数据库分区

接下来，我们推荐阅读一个很棒的4篇系列文章"Scalability for Dummies"教程。它重复了上面提到的一些主题，但也引入了几个重要的新概念：

- 使用NoSQL代替扩展关系型数据库
- 异步处理

你还会了解如何处理两大瓶颈：处理大量用户和处理大量数据。

最后，你可能还想阅读一篇关于数据库分片的教程。它是一种非常常见且强大的数据库扩展方式。
